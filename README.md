# Leadership DNA Report Builder

An MVP scaffold for turning reusable Leadership DNA content into polished client reports. It includes an authenticated consultant workspace, client groups, reusable content blocks, a TipTap rich-text report editor, and an email-delivery queue endpoint.

## Stack

- React + TypeScript + Vite
- Express + TypeScript + Prisma
- PostgreSQL (Docker Compose included)
- TipTap rich-text editor
- JWT authentication (passwords hashed with bcrypt)

## Run the packaged app

With Docker Desktop running, start the entire application with one command:

```sh
docker compose up --build
```

Open `http://localhost:8080`. The stack starts PostgreSQL, applies committed Prisma migrations, starts the API, and serves the built web app. The seeded login is `demo@leadershipdna.com` / `welcome123`.

The database is kept in the `postgres_data` Docker volume, so your data remains after stopping the stack. Use `Ctrl-C` to stop it, then run `docker compose down` to remove the containers. To start it in the background, use `docker compose up --build -d`.

### Optional configuration

The defaults are ready for local use. To change the browser port, database password, or JWT secret, copy [`.env.example`](.env.example) to `.env`, update its values, and run the same command. `APP_PORT` defaults to `8080`.

### Local development without Docker

For live-reload development, install Node.js 22+, provide `DATABASE_URL` and `JWT_SECRET` in `apps/api/.env` and `VITE_API_URL=http://localhost:4000/api` in `apps/web/.env`, then run the existing database, Prisma, seed, and `npm run dev` commands as needed. The packaged Docker workflow above is the supported quick-start path.

## PDF exports

Use **Export PDF** on a report card or in the report editor. Editor exports include the current unsaved title and content without saving them. Exports include formatted report content in block order and omit private facilitator notes and recipient emails.

PDFs are generated by Playwright Chromium through the authenticated `POST /api/reports/:id/pdf` endpoint. Docker installs Chromium and its system dependencies automatically. For local development, run `npx playwright install chromium` after `npm install` (on Linux use `npx playwright install --with-deps chromium`). Rebuild existing Docker images after updating.

Run `npm run test -w @leadership-dna/api` after installing Chromium to check PDF generation, formatting, HTML escaping, block order, and omission of private information.

## MVP boundaries

The send endpoint creates a durable `ReportDelivery` record and marks the report sent. Connect a transactional provider (Resend, Postmark, SES) inside `POST /api/reports/:id/send` to deliver actual emails and attach the PDF. PDF export is available separately; email delivery is still record-only.
